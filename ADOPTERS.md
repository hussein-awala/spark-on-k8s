# Adopters

This file lists organizations and projects that use spark-on-k8s. It helps people
evaluating the project see where it runs, and helps maintainers learn which parts
matter to users. Entries are self-reported. A listing is not an endorsement,
certification or support agreement in either direction; see
[support boundaries](docs/user-guide/support.md).

## Add your organization

Open a pull request that adds one row to the table below, keeping rows in
alphabetical order by organization:

- **Organization**: the organization or project name.
- **Use case**: one or two sentences on what you run and which parts you use, such
  as the Python SDK, CLI, API and console, Airflow provider, Helm chart or the
  experimental dbt adapter.
- **Link**: a public page for the organization, or a public write-up of your use.
- **Contact** (optional): a GitHub handle maintainers can mention with questions
  about your use. Do not add email addresses or phone numbers.

Only add an organization you are allowed to name publicly, and include only public
information. Sign your commit as [CONTRIBUTING.md](CONTRIBUTING.md#before-a-pull-request)
describes; a change to this file needs no runtime checks. Open another pull request
to update or remove your entry. Maintainers also remove an entry when its
organization asks.

If you cannot be named publicly, you are still welcome to describe your use in
[Discussions](https://github.com/hussein-awala/spark-on-k8s/discussions).
